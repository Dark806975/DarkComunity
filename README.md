# DarkComunity

**Official repository of DarkComunity, powered by Dark, founder of Otro_mas. Hub for original music, sound projects, gaming tech, and interactive content.**

DarkComunity is the main website for Dark's creative projects, including original music made with BandLab, gaming videos and live streams, technology interests, and the DeadCreep Minecraft server for Java and Bedrock.

## Website

The homepage is `index.html`. It is a responsive, single-page site written in HTML, CSS, and a small amount of JavaScript.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After GitHub Pages finishes publishing, the site should be available at:

   https://dark806975.github.io/DarkComunity/
